What's new in 1.2

Sharing
- Household invites now use Apple's native sharing sheet — fixes the spinner that could appear when inviting via Messages
- Share status saves before the invite sheet opens, so resending an invite always works

Sync
- Fixed a sync loop triggered by leftover share records on a household
- Fixed an edge case where shared household data could be removed during sync recovery
- Improved logging in release builds so sync issues are easier to diagnose

Apple TV
- Fixed empty state screens
